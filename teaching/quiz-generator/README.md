# quiz-generator — 문제은행 → 4지선다 HTML 시험·학습 페이지

파이썬 파일 하나(`bank.py`)에 문항을 적으면 브라우저에서 바로 푸는 HTML 두 종류를 만든다.
설치할 것 없음(Python 표준 라이브러리만).

| 스크립트 | 만드는 것 |
|---|---|
| `gen.py` | **확인 시험** — 다 풀고 제출하면 채점 (`<제목>_확인시험.html`) |
| `gen_study.py` | **즉답 학습** — 보기를 누르는 순간 정답·해설이 열림 (`<제목>_즉답학습.html`) |

두 스크립트는 같은 규칙으로 보기를 회전시키므로 문항 번호와 보기 순서가 항상 같다.

## 사용법

```bash
python3 gen.py
python3 gen_study.py
```

`bank.py` 는 형식을 보여 주는 예시다. 본인 문항으로 바꿔 쓴다.

```python
TITLE = "미생물학"                      # HTML 제목·파일명에 쓰인다

CH1 = ("1장 · 미생물의 분류", [
    ("질문", ["보기1", "보기2", "보기3", "보기4"], 2, "해설"),   # 정답번호 1-4
])
SECTIONS = [CH1]
```

- `**굵게**` 와 `*학명*` 은 HTML·마크다운 양쪽에서 자동 변환된다.
- 해설의 줄바꿈은 `\n`.
- 원래 문항은 정답이 한 번호에 쏠리기 쉬워서, `gen.py` 가 보기를 회전시켜 **정답 위치를 ①→②→③→④ 로 고르게 분배**한다. 해설에서 오답을 `①②③④` 로 가리키면 그 번호도 같은 회전으로 자동으로 바뀐다. 그러니 해설에는 **원래 보기 순서의 번호**를 쓴다.
- 실행할 때 보기 4개 여부·정답 범위·중복 문항을 자동 검사한다.

HTML을 직접 고치지 않는다. 다음 실행 때 덮어써진다.

## 선택 설정 (환경변수)

| 변수 | 뜻 |
|---|---|
| `QUIZ_OUT` / `QUIZ_STUDY_OUT` | 출력 HTML 경로 |
| `QUIZ_NOTE` | 마크다운 노트 경로. 주면 그 노트의 `# C. 예상문제` ~ `# D. 마무리 체크` 사이를 문항·정답표로 갈아 끼운다 (Obsidian 시험대비 노트용) |
